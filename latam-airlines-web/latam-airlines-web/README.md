# LATAM Airlines — proyecto web educativo

Sitio web multipágina de demostración inspirado en la aerolínea LATAM Airlines. No es un sitio oficial ni está afiliado a LATAM.

## Páginas
- `index.html`: portada y buscador de vuelos demostrativo.
- `pages/destinos.html`: destinos inspiracionales.
- `pages/experiencia.html`: información y enlaces a servicios oficiales.
- `pages/nosotros.html`: presentación general.
- `pages/contacto.html`: canales oficiales y formulario demostrativo.

## Tecnologías
HTML5, CSS3 y JavaScript vanilla. Incluye diseño responsive, menú móvil, animaciones de entrada con Intersection Observer y formularios de demostración.

## Cómo ejecutar
Abre `index.html` en tu navegador. Para desarrollo, puedes abrir la carpeta en Visual Studio Code y usar la extensión Live Server.

## Importante
- El buscador no consulta vuelos, precios ni disponibilidad.
- El formulario de contacto no envía ni almacena información.
- Las imágenes se cargan desde Unsplash y requieren conexión a Internet.
- La información de vuelos, equipaje, check-in y reservas debe confirmarse en el sitio oficial: https://www.latamairlines.com/pe/es
